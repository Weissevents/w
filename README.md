# Weiß Events – GitHub Pages

Diese Version ist vollständig für GitHub Pages vorbereitet.

## Upload
Den **Inhalt dieses Ordners** in das Root des GitHub-Repositories hochladen. `index.html`, `style.css`, `script.js`, `CNAME`, `assets/`, `leistungen/` und `en/` müssen direkt auf oberster Ebene liegen.

## Enthalten
- sichtbare Logo-Dateien in `assets/`
- überarbeitete Kontakt-/Sprachleiste
- vollständige englische Website unter `/en/`
- DE/EN-Verknüpfungen
- frei gestaltbare Events statt Hochzeiten
- Weiterleitungen alter Hochzeits-URLs
- Impressum mit Amtsgericht Duisburg, HRB 40929
- aktualisierte Sitemap und SEO-Metadaten
